jpdao-org/llc-dao-bylaws [Issue #6「[トレジャリー管理規程] wip版v1.0の正式化と付随修正」](https://github.com/jpdao-org/llc-dao-bylaws/issues/6) への対応。

定款ver2.0時代の草案 `wip/トレジャリー管理規程v1.0.md` を、**定款ver3.3・現行規程類（規程管理規程／DAO総会規程ver2.1／運営規程ver2.1／トークン規程ver2.2）と整合させた正式化ドラフト** `06_トレジャリー管理規程ver1.0.md` に改め、正式化にあたって判断が必要な論点を仮置きとともに整理した。

- **正本**: 定款ver3.3本文（リポジトリ直下 `01_【社員権トークン＋ガバナンストークン】合同会社型DAO定款ひな形ver3.3.md`）第12条第3項
- **方針**: 「整合した規程を先に作ってしまい、その上で判断が必要な論点をまとめる」。判断が必要な箇所はドラフト本文・別紙に**仮置き**し、②で選択肢と仮置きの理由を示す
- **設計原則**: 「規程は最小限、可変値は別紙へ」（[新規メンバー向け資料 3-1](../../stock/新規メンバー向け_定款改定の経緯と設計思想.md)）に従い、金額・人数・頻度などの可変値は新設の `appendices/トレジャリー別紙.md` に分離
